# AI Home Studio

AI Home Studio 是面向家装设计场景的 AI 驱动三维空间设计平台。

## 项目目标

- 从户型图快速建立可编辑三维空间
- 导入真实家具模型并完成选中、替换和尺寸校准
- 提供第一人称空间漫游
- 提供照片级路径追踪渲染
- 将设计方案与真实商品、SKU、预算和施工信息联动

## 当前阶段

项目处于技术底座评估与产品架构阶段，尚未发布可用的商业版本。

当前正在评估的开源技术基线：

- [3D New Era AI](https://github.com/leandrodaf/3d-new-era-ai)
- 许可证：MIT OR Apache-2.0
- 评估快照：`404a32385b7a5e4c28c51ebdf5d6ff529e6d55dd`
- 上游代码保持独立，不直接作为本仓库的提交历史

## 计划能力

1. 户型和空间建模
2. 家具资产与商品库
3. AI 方案生成和约束检查
4. 实时三维编辑
5. 高保真渲染任务
6. 项目、版本和协作管理
7. 商品 SKU 与预算联动
